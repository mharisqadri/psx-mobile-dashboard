# PSX Mobile Intelligence Dashboard

Public static frontend only. Supabase Authentication and Row Level Security
protect the private scanner snapshot. This repository must never contain a
service-role key, portfolio database, backups, or PSX engine source.

Required GitHub Actions repository secrets:

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY` (publishable/anon browser key only)

GitHub Pages source must be set to **GitHub Actions**.
